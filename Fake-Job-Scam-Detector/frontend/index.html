    ABOUT THE PROJECT

    Fake Job / Internship Scam Detection

    This project aims to detect potentially fraudulent job and internship postings. The system analyzes job information, suspicious keywords, salary claims and other patterns using NLP + ensemble machine learning to provide a risk assessment.

    ScamShield ML

    An AI-powered employment fraud detection system built for college ML project demonstrations.

    Tech Stack

    • Python / Flask
    • Scikit-learn
    • XGBoost
    • TF-IDF / NLP

    Dataset

    • EMSCAD
    • 17,880 job postings
    • ~4.8% fraudulent
    • Kaggle Dataset

    Red Flags to Watch

    • Unrealistic salaries
    • Vague descriptions
    • Upfront fee demands
    • No company info
